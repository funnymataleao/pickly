# Pickly result-details release metadata

Use this copy for the App Store version that first ships the expanded Open Food Facts result details.

For every storefront localization:

- add the localized feature bullet to the existing App Description;
- replace `What's New in This Version` with the localized release notes;
- preserve the full Privacy Policy URL;
- preserve the full Apple Standard EULA URL:
  `https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`.

## English (U.S.)

Description feature bullet:

> • Expanded product facts: nutrition, serving, allergens, additives, and data-source transparency

What's New:

> Product results now show more verified details:
> • Expanded nutrition facts, serving and package information
> • Allergens, possible traces, and additives when available
> • Data source, completeness, and last update
>
> We also improved personalization and made explanations clearer across all supported languages.
